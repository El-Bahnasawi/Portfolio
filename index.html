      Flagship Project

      AI-Powered Hate Speech Moderation

      Feb 2025 – Jun 2025
      🎓 Graduation Project 📄 Preprint

      Built a browser extension that blurs hateful English text on Twitter and YouTube in real time. The system uses a three‑layer pipeline: a fast rule‑based filter catches obvious cases, then a LoRA‑tuned BERTweet model (trained on 530k+ tweets) handles the rest with 84.5% macro‑F1. All feedback is stored in Supabase to continuously improve the model, and the research led to an arXiv preprint.
